# Basic-Recursive-Calculator
Bu C programı, recursive fonksiyonlarla üs alma, logaritma hesaplama ve dizi içinden maksimum değeri bulma işlemleri yapar. Kullanıcıdan alınan girdilerle işlemleri gerçekleştirip sonuçları ekrana yazdırır. math.h gibi kütüphanelerden fonksiyon kullanmadan hesaplama yapılır.
